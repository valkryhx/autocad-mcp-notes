# 沿墙机柜的整排检修通道

从项目根目录运行。两个参数一起传入，每次检查一排。例中的 1500 mm 来自本项目对 C01 的要求。其他排用各自的项目净宽。

```bash
D:/git_codes/Autocad-MCP/.venv/Scripts/python.exe -m tools.text_overlap draw_test/Drawing2.dxf --rack-loop C01 --min-rack-loop-mm 1500 --json
```

## 如何测

- 用 `CAB_ID` 精确匹配 `排号-数字`，如 `C01-12`。从块参照展开后的实体读外框，将共边的直排视为一个整体。报告列出每个柜号对应的外层块句柄。
- 从已核对的墙内面和门洞确定房间，向柜排四边同时外扩，保留四个完整方角。第一次接触墙面、其他柜体、设备占地或房门开启扇区时的宽度记为 `clear_mm`。设备仅占住拐角也会限制环道。等于要求时通过。
- `IT-MAINT-LOOP` 是专用示意线层。该层的路线以及纸面文字都不能证明通道存在。房门按整段开启过程检查，柜体按柜门关闭时的轮廓测量。设备抽出、柜门开启空间和消防疏散另行核验。

## 如何读结果

| `rack_loop.status` | 工程含义 | 核对位置 |
|---|---|---|
| `pass` | 图示几何能容纳所要求的连续环带 | `room_id`、`cabinet_count`、`clear_mm` |
| `fail` | 可留净宽小于要求，产生 `rack_loop_clearance` | `limiting_walls` 给墙的方位，`limiting_handles` 给限制物句柄，`wall_gaps_mm` 给四侧到墙距离 |
| `not_checked` | 证据不足，需补充图元或人工核验 | `reason` 给原因。全图退出码为 `2` |

目前支持声明毫米的模型空间、带 `ACADMCP_ARCH` 记录且墙门与实物一致的轴对齐矩形房间、连续直排矩形柜体、带单一矩形占地轮廓的设备块、独立矩形或圆形占地和轴对齐平开门。斜排、异形/多义块、无法识别的障碍或缺失的建筑记录会使本项进入 `not_checked`。图层及块的实际用途应与这些建模约定一致。

按排判读时读取 `rack_loop`。整条命令还会检查其他房间、门和文字，其他项目有发现时整图退出码仍是 `1`。DWG 经 AutoCAD 转换副本读取。如果本机 COM 报 `<unknown>.Open`，可用项目记录的控制台流程转换独立 DWG 副本，再对转换结果运行相同参数。
